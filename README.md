# POH MAL Logistics Logger

Offline-first logistics logging PWA for Singapore ↔ Myanmar operations.

## Stack
- Vite + React + TypeScript
- PGlite for in-browser storage
- Tailwind CSS
- react-router-dom
- ZXing barcode scanning
- vite-plugin-pwa

## Local development
```bash
npm install
npm run dev
```

## Validation
```bash
npm run build
npm run lint
```

## Default local credentials
- Admin: `admin123`
- Staff: `staff123`
